# Free Marketing

## About

**Free Marketing** is a free-first digital marketing system being built for **Alamir Pack**.

The goal is to build a practical marketing workflow using free tools first, while documenting what we do, what works, what fails, and what we learn.

## Main Objective

Build a simple and reusable digital marketing system for Alamir Pack that covers:

* Research
* Strategy
* Content
* Lead generation
* Customer communication
* Measurement
* Experiments
* Lessons learned

## Core Principle

> **Free-first:** We do not use paid tools or services unless a real need is proven.

## Workflow

**Analyze → Decide → Execute → Measure → Learn**

Every important experiment should follow this process and be documented.

## Main Tools

The system may use free tools such as:

* Claude
* ChatGPT
* Gemini
* Google Drive
* Google Sheets
* Google Forms
* Canva
* CapCut
* Meta Business Suite
* WhatsApp Business
* Google Business Profile
* GitHub

Tools may change over time based on actual results and requirements.

## Source of Truth

For the Alamir Pack website, the current source of truth is:

**Start App / GitHub**

Website changes must not be made without explicit approval.

## Rules

1. Do not pay for a tool before the need is proven.
2. Do not make website changes without explicit approval.
3. Document important experiments and their results.
4. Record failures as well as successes.
5. Do not store passwords, API keys, secrets, or customer personal data in this public repository.
6. Keep the system simple and improve it step by step.

## Current Phase

**Phase 1 — Foundation**

We are currently building the basic structure of the marketing system and documenting the tools, workflow, experiments, and lessons learned.
